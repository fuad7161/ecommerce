Public API (v1)

JSON API under /api/v1. Money values are integers in poisha (1 taka = 100 poisha). Prices and totals are always computed by the server. The full machine-readable contract is the OpenAPI 3 specification — import it into Postman, Insomnia or Swagger Editor.

MethodPathDescription
GET/api/v1/categoriesCategory tree
GET/api/v1/productsSearch & filter: q, category, min, max, in_stock, on_sale, sort, page
GET/api/v1/products/{slug}Product details and variants
GET/api/v1/delivery-zonesDelivery zones and charges
POST/api/v1/cart/quoteServer-priced cart
POST/api/v1/ordersGuest COD order (header Idempotency-Key)
POST/api/v1/orders/trackTrack by order number + phone

Example

curl -X POST {{.AppURL}}/api/v1/orders \
  -H 'Content-Type: application/json' -H 'Idempotency-Key: 3f2a9c1e-7b4d-4e0a-9a51-0c1d2e3f4a5b' \
  -d '{"name":"Rahim Uddin","phone":"01712345678","district":"Dhaka","area":"Mirpur",
       "address":"House 12, Road 5, Block C","zone_id":1,"payment_method":"cod","confirmed":true,
       "items":[{"sku":"BZ-1003","qty":1}]}'
